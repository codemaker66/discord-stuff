Questions

Good to know

Is it safe? Does it send my login anywhere?

You never paste a token, a password or any code. It installs like any browser extension and runs entirely inside your own Discord tab (or the Discord app, through Vencord or BetterDiscord), using the session you're already logged in with — your login and messages never leave Discord.

The userscript talks to Discord and nothing else; Tampermonkey itself fetches new versions of it from GitHub. The BetterDiscord plugin also asks GitHub once each time it starts whether there's a new version, and in the Discord app Vencord checks this project's GitHub releases for new builds. No servers of ours, no tracking~ ♡ The whole thing is public on GitHub, so anyone can check.

Windows says it “protected your PC” — is the installer OK?

That blue box is Microsoft Defender SmartScreen. It shows for new apps that Windows hasn't seen many people run yet — it doesn't mean anything was found. Press More info, then Run anyway.

Want to check first? Every release lists the installer's SHA-256 checksum, and all the code is public on GitHub.

Can it delete other people's messages?

No. Discord only lets you delete your own messages, and the purifier only ever asks for yours. DMs with anyone you shield are left alone, even mid-purge, and Bardo and Dopa are shielded from the start~ ♡ Shields cover one-to-one DMs, not group chats.

Can I undo a purge?

No — deleted means deleted. That's why it counts first and asks you to hold the button. Pause or Stop any time; nothing after that point is touched.

Does anyone get told?

Discord doesn't notify anyone when you delete a message — it just quietly disappears for everyone. A server's own logging bot may have kept a copy; that's outside anyone's reach but the server's.

Could my account get in trouble?

Honest answer: Discord's terms don't allow automating your account, and any tool like this carries a small risk. The purifier works at a human-ish pace (about 40 messages a minute), slows down whenever Discord asks, and never runs on its own — you start every purge. Use it at your own discretion.

The Discord app version runs inside Vencord, a client mod, and client mods are against Discord's terms too — the same small risk, the same honest answer.

How long does it take?

About 40 messages a minute, so 1,000 messages take around 25 minutes — a pace Discord is happy with, and slower whenever it asks for a break. A scan tells you the estimate up front; you can minimise the panel and keep chatting while it works. Keep the Discord tab open until it's done.

How do updates work?

Tampermonkey checks for new versions automatically. If you want it now: Tampermonkey icon → Utilities → Check for userscript updates, or press Install (or Reinstall) in step 3.

On BetterDiscord, the plugin checks each time Discord starts and asks before it updates.

In the Discord app, Vencord fetches new builds from this project's releases by itself and tells you to restart Discord. It also puts itself back after Discord updates.

How do I remove it?

Tampermonkey icon → Dashboard, then the bin next to the Purifier. Or remove Tampermonkey itself. On BetterDiscord, delete the plugin file. In the Discord app, run DopasPurifierSetup.exe again and press Uninstall.

Nothing shows up in Discord — help!

Nine times out of ten it's the Allow User Scripts step: on Chrome, Edge, Opera and Brave the Allow User Scripts switch (or Developer mode) must be on. Then make sure Tampermonkey is enabled, the script is switched on in its dashboard, and reload Discord. Still stuck? Open an issue.
